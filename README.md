# Σημειώσεις Νομικής — Powered by ANEF Nomikis

Στατικό site (HTML/CSS/JS) για GitHub Pages.

## Δημοσίευση στο GitHub Pages
1. Ανεβάστε όλα τα αρχεία σε ένα αποθετήριο GitHub.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`.

## Ροή έγκρισης σημειώσεων
1. Οι επισκέπτες στέλνουν το αρχείο τους από τη Google Form (σύνδεσμος στο `data/config.js`).
2. Η ομάδα ελέγχει την υποβολή.
3. Μετά την έγκριση: βάζετε το αρχείο στο `notes/` και προσθέτετε μια εγγραφή στο `data/notes.js`.
   Ό,τι δεν έχει εγκριθεί δεν εμφανίζεται στο site.

## Περιεχόμενο
- `data/courses.js` — μαθήματα (Οδηγός Σπουδών 2026-2027)
- `data/faq.js` — ερωτήσεις/απαντήσεις με σελίδα του Οδηγού
- `data/m365.js` — βήματα Microsoft 365 από τη σελίδα του Κέντρου Δικτύου ΕΚΠΑ

Τα δεδομένα μπαίνουν μόνο από τις επίσημες πηγές.
